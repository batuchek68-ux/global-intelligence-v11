# Global Intelligence System

## Overview

Global Intelligence v12 是一个 AI 驱动的国际贸易情报平台，专注于跨境 B2B 工程贸易。

## Architecture

### Core Components

- **Orchestration Engine**: 多 Agent 编排系统
- **Risk Gate**: 风险评估和审批门控
- **Knowledge Base**: Obsidian 连接的知识库
- **Intelligence Center**: 情报收集和分析

### Agent Types

1. **ClassifierAgent**: 意图分类
2. **ExtractorAgent**: 实体提取
3. **EvidencePlannerAgent**: 证据规划
4. **RiskGateAgent**: 风险门控
5. **SynthesizerAgent**: 结果综合

## Key Features

- 自动化情报收集
- 风险评估和审批流程
- 多平台内容生成
- 实时市场监控
- 知识图谱构建
