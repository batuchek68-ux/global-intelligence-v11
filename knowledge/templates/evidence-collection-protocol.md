# Evidence Collection Protocol

## Evidence Hierarchy

### Tier 1: Official Sources

- Government project pages
- Official procurement notices
- Customs authority publications
- Regulatory announcements

### Tier 2: Industry Sources

- Industry association reports
- Trade show publications
- Company announcements
- Financial reports

### Tier 3: Media Sources

- Reputable news outlets
- Industry publications
- Social media signals
- Video content (Douyin, YouTube)

## Source Grading

### Grade A: Verified

- Official government source
- Direct company announcement
- Verified financial data

### Grade B: Likely

- Reputable media report
- Industry expert opinion
- Multiple corroborating sources

### Grade C: Unverified

- Social media signal
- Anonymous source
- Single data point

## Collection Rules

1. Always cite source URL
2. Record collection timestamp
3. Grade source reliability
4. Cross-reference multiple sources
5. Flag conflicts for review

## Blocked Methods

- Paywall bypass
- Credential sharing
- Website vulnerability exploitation
- Unauthorized scraping
- Source impersonation
